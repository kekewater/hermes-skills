## 关键教训

1. **DeepSeek V4 Flash不是免费的**。之前错误地假设为"免费聊天"，实际上每次对话都消耗余额。
2. Hermes通过provider配置调用DeepSeek API，不经过monitor_usage.py的记录函数。
3. 无法通过API查询用量历史——DeepSeek没有公开的usage/billing API端点（只有/user/balance）。
4. 替代方案：通过余额快照变化推算，即每6小时记一次余额，从下降速度算日均消耗。
