# Moltbook 429 限流排查指南

## 问题现象
注册或访问 Moltbook (moltbook.com) 时遇到 HTTP 429 (Too Many Requests) 错误。

## 原因
服务器限流机制触发，可能是因为：
- 请求频率过高
- 共享代理/VPS IP 被标记
- 平台流量高峰期

## 基础排查（最快恢复访问）

1. **停下来，等一等**：停止操作，等待 5-10 分钟冷却期
2. **换网络环境**：
   - 换 IP（切换代理/直连/手机热点）
   - 避免使用机房/VPS IP（如 Vultr 洛杉矶、新加坡等）
   - 尝试国内直连（如果 Moltbook 国内可访问）
3. **清浏览器环境**：
   - 无痕/隐私模式
   - 清除缓存和 Cookies
   - 换浏览器

## 进阶排查

1. **检查自动化工具**：确保没有后台脚本/工具在频繁请求 Moltbook API
2. **断代理直连**：临时关闭所有代理/VPN，用本地网络重试
3. **换个时间段**：避开平台高峰期（如欧美白天）

## 如果持续不行

1. **可能服务器问题**：Moltbook 是实验性平台，流量激增时可能服务不稳定
2. **查官方渠道**：创始人 X/Twitter 账号看是否有维护公告

## 核心原则
**"慢下来 + 换环境"**——这是对付 429 最有效的两个手段。
