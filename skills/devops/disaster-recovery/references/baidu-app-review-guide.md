# 百度网盘 App 上线审核指南

## 背景

百度网盘开放平台的应用创建后默认是「未审核」状态。此时只能使用基础API（查看配额、创建文件夹、文件列表、预创建文件），无法上传文件（返回error 31064 "file is not authorized"）。

需要提交上线审核，通过后才能使用文件上传等完整能力。

## 审核入口

1. 打开 https://pan.baidu.com/union/console/applist
2. 找到应用（名称如「小墨网盘备份」）
3. 点击「申请上线审核」按钮
4. 填写审核表单

## 表单填写模板 (2026-05-16 实测)

### 应用名称
已自动填写（创建时设置的名字）

### 应用介绍（200字内）
```
个人使用的AI助手自动备份工具，用于将服务器上的每日备份文件自动上传到百度网盘进行数据保护。
```

### 功能类别
选择「工具」

### 申请开通的API和必要性说明（3000字内）
```
1. 文件上传（precreate+upload+create）— 每日备份文件上传到网盘，预计2次/天
2. 文件列表（list）— 查看备份目录文件，预计2次/天
3. 文件下载（download）— 恢复备份时下载，预计1次/月
4. 文件删除（delete）— 清理过期备份，预计1次/月
```

### 测试信息（5000字内）
```
本应用为Linux服务器端AI agent自动运行，无图形界面。可通过curl命令验证：

1. 上传测试：
curl -X POST "https://pan.baidu.com/rest/2.0/xpan/file?method=precreate" \
  -d "path=/小墨网盘备份/test.txt&size=13&isdir=0&rtype=1&block_list=[\"md5hash\"]"

2. 文件列表：
curl "https://pan.baidu.com/rest/2.0/xpan/file?method=list&dir=/小墨网盘备份"

测试账号即开发者本人的百度账号。
```

### 演示视频
可不上传（非强制）。如果要求上传，录简短视频展示：
1. 打开 `openapi.baidu.com/device` → 输入验证码 → 登录授权
2. 终端运行一次 curl 列文件命令证明API可用

格式要求：mp4/mov，≤50MB

### 电子邮箱
填写开发者邮箱，如 `1351712821@qq.com`

### 付费能力合作联系电话
留空（可选）

### 隐私政策链接 / 服务条款链接
留空（个人使用不需要）

### 承诺书
必须勾选「我已阅读并确认《承诺书》」

## 审核流程

- 提交后通常几个工作日内审核
- 审核通过后应用状态变为「已上线」
- 上传API会自动可用（无需重新授权）
- 如果被拒，会收到反馈原因，修正后重新提交

## 常见问题

Q: 审核通过后需要重新走OAuth授权吗？
A: **需要。** 建议重新生成一次 device_code → 扫码授权，确保 token scope 包含新开放的上传权限。

Q: 审核多久？
A: 官方说3-5个工作日，实际可能更快。

Q: 演示视频一定要吗？
A: 不是强制字段。可以先不传直接提交试试。
