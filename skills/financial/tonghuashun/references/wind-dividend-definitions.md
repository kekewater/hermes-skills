# Wind 股息率四定义与对比

## Wind 的四种股息率指标

Wind 金融终端对同一只股票提供**4种不同的股息率**计算方式。在我们的脚本中，计算的是 **股息率(近12个月)**。

### 定义对照

| # | Wind 字段名 | 含义 | 计算公式 | 招商银行示例(2026/5/13) |
|:-|:--|:--|:--|--:|
| ① | **股息率(报告期)** | 最近一期年报/中报宣告分红的股息率 | 最近一期宣告分红 ÷ 股价 | 20元/10股÷37.88 = **5.32%** |
| ② | **股息率(近12个月)** | 过去12个月已到账分红合计的股息率 | 近2次已实施分红合计 ÷ 股价 | 30.13元/10股÷37.88 = **7.95%** ✅ |
| ③ | **股息率TTM** | Trailing Twelve Months —— 基于最近一期报告期 | = ①（Wind 实现） | **5.32%** |
| ④ | **股息率TTM(剔除特别派息)** | TTM 扣除特别派息 | = ③（无特别派息时） | **5.32%** |

### 关键区别

```
报告期股息率(①)     = 最近宣告的年报/中报分红 / 当前股价
近12个月股息率(②)   = 近2次已实施到账分红之和 / 当前股价  ← 本技能使用
TTM(③)              = 基于过去12个月财报追溯的股息率
```

**当公司一年分两次红时**（如银行股）：
- ① 只反映最近一次宣告的分红（可能是半年的），**偏低**
- ② 反映实际到手的全年分红，**准确反映持有收益**
- ③ 与 ① 相同（Wind 的 TTM 实现方式）

**当公司一年只分一次红时**：
- ① = ② = ③，三种定义趋同

## 核实方法

### 1. 确认全年分红总额

```python
import akshare as ak
df = ak.stock_history_dividend_detail(symbol="600036")
impl = df[df['进度']=='实施']
# 取最近2次已实施分红
total = sum(float(r['派息']) for _, r in impl.head(2).iterrows() if r['派息'])
print(f"全年每10股分红: {total}元")
print(f"全年每股分红: {total/10}元")
```

### 2. 交叉验证（与 Wind 对比）

| 日期 | 股价 | 本技能(近12个月) | Wind(近12个月) | 差值 |
|:--|--:|--:|--:|:--|
| 2026-04-01 | 39.82 | 7.57% | 7.57% | 0.00% ✅ |
| 2026-04-15 | 38.35 | 7.86% | 7.55% | +0.31% |
| 2026-05-06 | 37.90 | 7.95% | 7.93% | +0.02% ✅ |
| 2026-05-13 | 37.88 | 7.95% | 7.95% | 0.00% ✅ |

### 3. 合理性信号（注意检查）

- 银行股股息率通常在 **5%~8%**（全年分红）
- 若计算值 < 3%，大概率只用了一次半年分红 → 检查 `dividend-history` 中 `dps` 字段
- 若计算值 > 10%，检查股价是否含权或分红数据异常

## 常见误用

```python
# ❌ 错误：只用最近一次分红
dps = float(impl.iloc[0]['派息']) / 10  # 10.13/10 = 1.013
dy = dps / price * 100                  # 2.67% ← 明显偏低

# ✅ 正确：取最近2次已实施分红（覆盖近12个月）
total = sum(float(r['派息']) for _, r in impl.head(2).iterrows() if r['派息'])
dps = total / 10                        # (20+10.13)/10 = 3.013
dy = dps / price * 100                  # 7.95% ← 与 Wind 一致
```

## 数据源说明

- **分红明细**: AKShare `stock_history_dividend_detail()`，按公告日期倒序排列
- **股价**: iFinD HTTP API（优先）或 AKShare 实时行情
- **Wind 对比数据**: 来自 Wind 金融终端导出，用于验证计算准确性
