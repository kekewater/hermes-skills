## K线接口 (`/api/qt/stock/kline/get`)

参数：`klt` = 101(日K), 102(周K), 103(月K), `fqt` = 1(前复权)

K线数据返回字符串数组，每行按逗号分隔：

| 索引 | 含义 | 需要÷100? |
|------|------|-----------|
| 0 (f51) | 日期 | ❌ |
| 1 (f52) | 开盘价 | ✅ |
| 2 (f53) | 收盘价 | ✅ |
| 3 (f54) | 最高价 | ✅ |
| 4 (f55) | 最低价 | ✅ |
| 5 (f56) | 成交量 | ❌ |
| 6 (f57) | 成交额 | ❌ |
| 7 (f58) | 振幅 | ✅ |
| 8 (f59) | 涨跌幅 | ✅ |
| 9 (f60) | 涨跌额 | ✅ |
| 10 (f61) | 换手率 | ✅ |

## 搜索接口 (`/api/suggest/get`)

参数：`input`=关键词, `count`=返回数量, `type`=14(全部)

返回 `QuotationCodeTable.Data` 数组：

| 字段 | 含义 |
|------|------|
| Code | 股票代码 |
| Name | 股票名称 |
| Market | 市场代码 |
| CodeType | 类型(1=指数, 2=股票, 3=基金) |

## 资金流向接口 (`/api/qt/stock/fflow/daykline/get`)

K线数据每行：

| 索引 | 含义 |
|------|------|
| 0 | 日期 |
| 1 | 主力净流入 |

| 3 | 小单净流入 |
| 4 | 中单净流入 |
| 5 | 大单净流入 |
| 6 | 超大单净流入 |
