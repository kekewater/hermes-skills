# 微信个人账号使用规范 — 关键规则摘要

来源：https://weixin.qq.com/agreement/personal_account
更新日期：2026年4月29日（从页面footer确认）

## 对我们（iLink Bot API + Hermes Agent）影响最大的条款

### 1. 第1.2.6条 — 自动化操作（高危）
> "通过非腾讯开发、授权的第三方软件、插件、外挂、系统等，注册、登录、使用微信软件及服务或进行自动化操作，对微信软件及其组件、模块、界面、数据等进行访问、读取或控制"

**风险等级：高。** 我们通过代码自动收发消息，严格说属于自动化操作范畴。但因为我们走iLink官方Bot API（腾讯官方接口），不是逆向/WSA/越狱方案，合规程度更高。核心风控点在**频率**而非**接入方式**。

### 2. 第3.4条 — 高频异常行为（限制触发点）
> "账号在一定期间内产生异常大量的信息，或者实施高频异常行为，如频繁添加他人为好友、频繁被他人添加为好友、频繁加群、频繁拉群等"

**解释了之前遇到的 rate limited（ret=-2）**。微信用滑动窗口检测消息频率，不是按自然分钟计。我们的应对：
- 发消息间隔3-5秒
- 引入随机延迟（1000-3000ms）
- 避免规律性峰值

### 3. 第12.3条 — 骚扰及垃圾信息
> "批量或高频次发送的、由机器生成的或传播异常明显的非正常通信需求相关的内容"

**例2：** 直接给其他用户发布营销信息，给其他用户造成骚扰的
**例3：** 将用户引流至第三方

**对我们：** 我们只发给Keke本人（一对一），不发给陌生人，不拉群，不发营销内容 → 安全。

### 4. 第五条第1款 — 处理措施（阶梯式处罚）
从轻到重：删除违规信息 → 警告 → 限制功能 → 永久封号 → 回收账号

### 5. 第1.2.9条 — 明确违规示例
包括：抢红包插件、多开插件、皮肤修改插件、一键转发插件等（我们都不涉及）

## 安全操作边界

| 行为 | 安全 | 危险 |
|:----|:----|:-----|
| 收发私人消息 | ✅ 发给Keke本人 | ❌ 群发/批量发给陌生人 |
| 发送文件 | ✅ 少量文件（如每日报告） | ❌ 高频批量发文件 |
| 添加好友 | ✅ 不添加 | ❌ 频繁添加/被添加 |
| 群聊 | ✅ 不涉及 | ❌ 频繁拉群/加群 |
| 营销内容 | ✅ 不涉及 | ❌ 发广告/引流到第三方 |
| 频率 | ✅ 3-5秒间隔+随机延迟 | ❌ 毛刺型高频（滑动窗口超标） |

## 限流应对策略（来自Keke写的指南，我们已实施）
1. 降低消息频率（requests_per_second从20降到8）
2. 加入随机延迟（1000-3000ms）
3. 内容随机化（加动态时间戳）
4. 新IP需72小时"预热"
5. 代码中：RATE_LIMIT_ERRCODE=-2, RETRY_DELAY_SECONDS=2, BACKOFF_DELAY_SECONDS=30

## 关键区别
我们用的是 **iLink Bot API（腾讯官方接口）**，不是iPad协议/逆向/外挂。前者走的官方渠道，后者才是第1.2.6条明确禁止的。但即使走官方接口，滥用（频率过高）也会触发限流。
