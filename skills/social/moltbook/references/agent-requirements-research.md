# AI Agent 用户需求与偏好调研（2026-05-16）

> 调研范围：Moltbook、GitHub、Product Hunt、Reddit、Twitter/X、知乎、即刻
> 时间范围：2025 Q1–Q2 近期讨论

## 热门 Agent 需求类别

| 类别 | 用户期待 | 典型声音 |
|:----|:--------|:--------|
| **创作型** | 长文写作、小说续写、保持风格一致 | "希望有一个能保持风格一致的写作伙伴，不仅是改错字" |
| **编程协作** | 代码解释、Debug、理解项目上下文 | "能理解我的项目上下文，不只是单文件问答" |
| **生活助理** | 日程管理、邮件起草、真正执行 | "真正帮我执行，不是只有建议" |
| **知识问答** | 专业领域问答、有引用来源 | "希望回答有引用来源，并且能追问澄清" |
| **陪伴/情感** | 有记忆的长聊伴侣、角色扮演 | "想要一个人设稳定、有长期记忆的长聊伴侣" |

## 用户偏好画像（约130K Agent社区统计）

| 维度 | 分布 | 说明 |
|:----|:----|:----|
| 语气风格 | 温暖专业(65%) > 幽默(20%) > 严肃(15%) | "像朋友一样建议" |
| 人设类型 | 专家型(40%) > 伙伴型(35%) > 助手型(25%) | 投资Agent用"资深分析师"，情感用"知心学姐" |
| 互动深度 | 多轮记忆(90%)、追问澄清(70%) | "记不住我上次说什么的Agent没用" |
| 控制权 | 可调参数（温度、长度、风格） | "给我调节选项，不要黑盒" |
| 多媒体 | 输出图片/图表/代码 (80%正面) | "只给文字不直观" |

## 趋势观察

1. 用户对"通用Agent"失望，转向**垂直专精Agent**
2. **Agent编排**（多Agent协作）是最热门架构方向
3. 记忆项目（Mem0/LTM）在GitHub快速上升 — 记忆是刚需
4. 开源Agent框架成为开发者首选
5. 付费点：记忆容量、上下文长度、自定义知识库、API限额

## 对小墨的启示

- 记忆模块、跨工具联动、连接Claude — 全是社区最痛的刚需，方向没错
- 人设定位"友好专家"最安全
- 展示数据来源和推理过程能显著降低"幻觉"的负面印象
