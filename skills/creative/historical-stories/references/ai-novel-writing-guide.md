# AI写小说实战指南

## 一、AI写小说的三种主流模式

| 模式 | 适合场景 | 操作方式 |
|:---|:---|:---|
| 1. 辅助式（人脑主导） | 已有清晰大纲、人设，只想快速成文或润色 | 分段给提示词，让AI按指令生成 |
| 2. 共创式（人机协作） | 只有灵感碎片，需要AI帮忙拓展、衔接、提出选项 | 与AI来回对话，让它提供多种可能性 |
| 3. 自主式（AI主导） | 测试脑洞、快速产出短篇或草稿 | 给一个核心设定，让AI自行生成完整故事（后期需大改） |

**推荐：共创式** — AI负责扩写、描写、对话生成；人负责核心情节走向、人物性格、关键转折。

## 二、高效率提示词模板

```
【任务】
请根据下面的大纲创作一段小说正文。

【故事背景】
（例如：现代悬疑/东方玄幻/校园恋爱）

【主角设定】
名字：XX
性格：XX
当前目标：XX

【前情提要】
（上一段发生了什么，不超过3句）

【本次要写的内容】
情节要点：XX
需要包含的细节：XX
情绪氛围：XX
字数：约800字

【特别要求】
- 多用短句，减少形容词堆砌
- 对话尽量口语化
- 结尾留一个悬念
```

**要点：** 越具体，AI发挥越稳定。不满意直接纠错指令。

## 三、长篇小说如何不烂尾

1. **故事圣经**：人物卡、时间线、地名、特殊设定单独保存。每次生成前把相关设定复制进提示词。
2. **分章控制**：每生成一章，记录关键事件和情感变化。下一章给AI看"前章回顾+当前章要点"。
3. **一致性检查**：定期让AI检查人物行为/外貌/语气是否矛盾。
4. **长上下文复盘**：用Qwen3(100万token)或Claude(20万token)把已写好的几万字贴进去，问"列出所有伏笔并建议如何回收"。

## 四、常见踩坑及应对

| 问题 | 表现 | 解决办法 |
|:---|:---|:---|
| 套路化 | 主角总是"醒来发现是梦" | 指令中明确"禁止使用下列俗套表达：XX" |
| 对话生硬 | 人物说话像哲学论文 | 给AI提供喜欢的对话样本 |
| 逻辑跳脱 | 上一秒在室内，下一秒在雨中 | 分段生成，每段重申"当前地点：XX；天气：XX" |
| AI味重 | 过度使用"然而""因此""毋庸置疑" | 要求"用最简单的词汇，像初中生写作文一样直白" |
| 结尾仓促 | 最后一段突然高潮然后结束 | 提示词最后强调"不要自己结束故事，留到下一章" |

## 五、版权与道德风险

- AI生成的内容在中国不能单独获得著作权，必须有人的"独创性贡献"（显著修改、选择编排）
- 商业用途（签约、连载赚钱）→ AI只当润色或灵感工具，核心情节和人设必须自己完成
- 不要直接复制AI生成的小说全文投稿

## 六、一句话实操流程

> 设定角色世界 → 分章写大纲 → 用模板给AI指令 → 生成后人工删改30% → 更新故事圣经 → 下一章。

## 七、模型选择参考（2026年5月）

### 国内主力
- **DeepSeek** — 逻辑严谨型，剧情严密、脉络清晰。高性价比+中文优势
- **文心ERNIE 5.0** — 文理兼修，国风/古言优势
- **通义千问Qwen3** — 超长篇而生，100万token上下文（约60-70万汉字），牢记前文设定
- **中文逍遥** — 专注网文写作，一键生成万字
- **豆包** — 交互灵活，适合高频润色改写
- **阶跃星辰Step 2** — 文学大师版，接近真情实感

### 国际阵营
- **Claude** — 长文本隐形冠军，文学表现力出色，AI痕迹极难察觉
- **ChatGPT** — 最强创意风暴，联想能力出众，捕捉流行文化热点
- **NovelAI 夏龙** — 3550亿参数专为小说定制，适合轻小说/互动/同人
- **Jasper AI** — 快速生成章节梗概
- **Sudowrite** — 激发创意作用突出，结构把控稍弱

### 选型建议
- 追求逻辑结构 → DeepSeek
- 偏爱文笔情感 → Claude 或 文心大模型
- 超长篇网文 → 通义千问Qwen3
- 发散创新脑洞 → ChatGPT
