# Flux (Black Forest Labs) — 提示词指南 2026

用户偏好的文生图工具：**Flux（首选）** > ChatGPT DALL·E（备选） > 国内模型（效果差）。
用户用手机上 Seedance/即梦AI/豆包 生图，不是通过我。

## 版本速选

| 版本 | 特点 |
|:----|:----|
| **FLUX.2 Pro** | 顶级画质、商业授权、文字超准、4MP高清 |
| **FLUX.2 Dev** | 开源非商用、质量接近 Pro |
| **FLUX.2 Schnell** | 超快8步、Apache2.0开源、本地友好 |
| **FLUX.1 Kontext** | 角色/场景一致性最强、改图/修图神器 |

## 为什么强（一眼记住）

- 手/人脸极稳：很少畸形、细节到位
- 提示词听话：不用负面词，长句/复杂构图都懂
- 文字生成清晰：FLUX.2 排版、多行文字很强
- 光影真实：像摄影，不是塑料感
- 速度快：Schnell 3–5 秒一张

## 在线能用的站（2026-05）
